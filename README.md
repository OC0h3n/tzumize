# אתר הרצאות — מדריך עריכה 🎤

אתר תדמית דו-לשוני (עברית 🇮🇱 + אנגלית 🇬🇧) למרצה. אתר **סטטי** לחלוטין — בלי התקנות, בלי build. פשוט פותחים את `index.html` בדפדפן.

## הרצה מקומית

- **הכי פשוט:** לחיצה כפולה על `index.html`.
- **מומלץ (כדי שווידאו ותמונות ייטענו נכון):** הרצת שרת מקומי קטן מתוך תיקיית הפרויקט:
  ```
  python -m http.server 8000
  ```
  ואז פותחים בדפדפן: `http://localhost:8000`

## איפה עורכים מה

### ✏️ טקסטים (כותרות, פסקאות, כפתורים)
הכל בקובץ **`js/translations.js`** — אובייקט `TRANSLATIONS` עם `he` (עברית) ו-`en` (אנגלית).
מצאו את המפתח, שנו את הערך בשתי השפות. זהו.

### 🎓 ההרצאות (כרטיסים)
ב-`js/translations.js`, בתוך `cards.lectures` (יש גרסה לכל שפה). כל כרטיס:
```js
{ icon: "🚀", title: "כותרת", desc: "תיאור קצר", tag: "נוער" }
```
אפשר להוסיף/למחוק כרטיסים — הם מתעדכנים אוטומטית.

### 💰 מחירים והנחות
ב-`js/translations.js`, במערך **`PRICING`**. לכל חבילה: `price` (מספר), `currency`, `name`, `desc`, ו-`features`.
- מחיר `null` = מציג "בהתאמה" (במקום מספר).
- `popular: true` = מסמן את החבילה כ"הכי פופולרי".
- טקסט ההנחות הכללי נמצא במפתח `pricing.note` (בשתי השפות).

### 🎬 רילסים / סרטונים — **רק מחליפים קובץ, בלי לגעת בקוד**
שימו קבצי וידאו בתיקייה **`assets/videos/`** עם השמות המדויקים:
`reel1.mp4`, `reel2.mp4`, `reel3.mp4`, `reel4.mp4` — **באותיות קטנות**.
- קובץ שקיים → הסרטון מופיע. קובץ שחסר → מוצג רקע צבעוני במקומו.
- תמונת תצוגה (אופציונלי): `reel1.jpg` וכו' בתיקייה `assets/images/`.
- לרענן את הדף אחרי ההחלפה (Ctrl+F5).

### 🖼️ תמונת המרצה — **רק מחליפים קובץ, בלי לגעת בקוד**
שימו תמונה בשם **`speaker.jpg`** (אותיות קטנות) בתיקייה `assets/images/`.
אם הקובץ קיים — הוא מוצג; אם חסר — מוצג ה-placeholder עם 📷.

> ⚠️ **חשוב:** תמיד אותיות קטנות בשם הקובץ ובסיומת (`speaker.jpg` ולא `Speaker.JPG`).
> במחשב זה אולי יעבוד בכל מקרה, אבל באתר החי (GitHub Pages) אותיות גדולות יישברו.
